## How to release (added after this day)

- Merge nothing into `integration` between opening a release PR and merging it, or re-read the PR's file list just
  before the merge. The description is written once; the contents are not frozen.
- A release that changes a file the evaluator hashes needs its row in the DEC-0044 note first.
- After the merge: `main`'s three workflows, then the site's version, then the host (it deploys itself within the
  hour when no job runs and the trading window is shut, unless the release changes units, helpers or the deploy).
